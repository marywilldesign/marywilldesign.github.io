Glyphs: corrupted

graphic design print personal project

This project considered how we obscure and censor text, especially when people are left to their own devices. Using web scraping and conditional programming, remixed this art piece originally intended to be a collaborative piece.

The text which I was censoring realtes to my other project, a website which I made by scraping the text from The Longest Collaborative Sentence and autoscrolling it using frontend development. The need for censorship came after I was seeing the sheer amount of profanities and every type of 'ism' you could imagine.

My aim was to create type that had movement and, similar to asemic writing, could mimic written forms from afar but, up close, bares no resemblance.

Through my research, I came across a number of different types of ways to obscure text. One which kept coming up was 'Zalgo', which is associated with horror from its diacritical marks (making the text seem corrupted in some way).

Once I had come up with a number of directions, I wanted to explore how these would look printed, away from the digital space – so I made a fontbook.
