Blackbox VJ tool

UX graphic design web dev personal project

2025

This (very much WIP) Visual Jockey web tool is a collaborative online space where anyone can play with text, visuals, and ideas without needing special software. It’s designed for experimentation—mixing, censoring, revealing, or reshaping content freely.

The controller UI is still evolving, but the visual output is intentionally unpredictable. Users can upload images, allowing personal input to directly shape generative results.

Feature list (so far)

  • gradient
  • grain
  • image upload
  • shape / object definer
  • movement direction
  • colour selection
  • webcam / external camera input
  • grid definer
  • shape warp
