Blackbox: 3D printed VJ synthesizer

UX web dev graphic design personal project

An analogue-to-digital visual synthesizer with a custom 3D-printed controller, exploring co-creation between hand, hardware, and real-time visuals.

2025 - 2026 · Designer and Developer

view site ↗

Supervisor: Stefan Ellmer

ASK

(Self-developed master's thesis) Explore how physical, tactile control can shape real-time generative visuals, creating a tool that feels more like an instrument than a piece of software.

PROBLEM

Most VJ tools prioritise screen-based interaction (mouse, keyboard, touch), which can feel disconnected from the performative, embodied nature of live visual mixing. The challenge was designing a physical controller that felt intuitive and expressive.

OPPORTUNITY

How might I design a hardware controller and software system that enables genuine co-creation between hand, hardware, and real-time visuals, where the physical interface becomes an extension of the body?

RESULT

A fully functional visual synthesizer with a custom 3D-printed controller, published as a master's thesis at blackboxvj.me.

CONTRIBUTION

  • Designed and built the entire system end-to-end: hardware design, SLA 3D printing, electronics integration
  • Developed the Raspberry Pi and analogue-to-digital conversion pipeline with Python middleware
  • Built the frontend real-time visual output system
