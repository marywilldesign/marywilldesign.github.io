Blackbox VJ tool

UX graphic design web dev personal project

2025

This (very much WIP) Visual Jockey web tool is a collaborative online space where anyone can play with text, visuals, and ideas without needing any special software. It’s designed so people can experiment freely from home—mixing, censoring, revealing, or reshaping content however they like.

The controller UI still needs some tinkering in terms of functionality and form... but the visual output is always surprising, especially since I added the ability to upload a photo, meaning users can really insert their own style into it.

Feature list (so far)

  • gradient
  • grain
  • image upload
  • shape / object definer
  • movement direction
  • colour selection
  • connect to external camera (web cam or external camera)
  • grid definer
  • shape warp
