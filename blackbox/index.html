Blackbox: 3D printed VJ synthesizer

UX web dev graphic design personal project

BLACKBOX is an analogue to digital visual synthesizer built around a custom controller with 16 knobs and 2 switches, exploring co-creation between hand, hardware, and real-time visuals. Developed as a master's thesis under the supervision of Stefan Ellmer, the physical controller is SLA 3D printed in a soft, transparent blobject shape, paying homage to early 2000s modular tech. It uses a Raspberry Pi 5 and analogue to digital converter to interpret controller values through Python into frontend visual output.
