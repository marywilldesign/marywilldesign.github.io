Remixed Collaborative Sentence

UX graphic design web dev personal project

An autoscrolling web art piece that uses web scraping to remix and recontextualise problematic language from a collaborative text experiment. The project is a remix of Douglas Davis's The World's First Collaborative Sentence, a pioneering digital artwork that was the first of its kind on the internet and ran for years. The original work is owned by the Whitney Museum of American Art.

2025 · Designer and Developer

view site ↗

ASK

(Self-developed brief) Build a piece that uses web scraping and remix techniques to surface and critique harmful rhetoric patterns, using an autoscroll format as the primary interaction (or lack thereof).

PROBLEM

Presenting critical commentary on ideology without simply reproducing or amplifying the source material.

OPPORTUNITY

How might I use scraping and re-contextualisation as a design technique to create critical distance from the source material rather than repeating it uncritically?

RESULT

A published, functioning web piece exploring this tension, submitted to the Grafill Visuelt competition.

CONTRIBUTION

  • Designed and built the scraping/remix system and autoscroll interface end-to-end
  • Defined the source material and censor logic to block profanities
  • Designed the pacing/scroll mechanic to shape how the critique lands
