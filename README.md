# marywildesign.com

The portfolio of Mary G. Wilson, UX/UI designer. It showcases selected work across UX/UI design, creative coding and installation design, alongside an about page and a CV.

Live at **https://marywildesign.com**

## What's where

```
index.html        the home page: intro, project cards and the CV panel
404.html          the "page not found" screen
robots.txt        points search engines at the sitemap
sitemap.xml       every page on the site

core/             the code every page shares
  style.css         the styles
  script.js         everything interactive
  projects.js       the project details and the CV

assets/           files every page shares
  mw.svg            the logo mark
  portrait-of-the-artist.jpg
  og.jpg            the home page's link preview image
  mary-wilson-resume.pdf
  fonts/            Neue Montreal and the clock's hieroglyphs

pages/
  about/            the about page

projects/         one folder per case study, with its page, images and videos
  collaborativesentence/  ibm/  kogl/  liveopencall/  modo/
  telus/  telus-informing-customers/  vancouverartgallery/  vj-controller/

.github/          publishing setup
```
