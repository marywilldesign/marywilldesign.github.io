Well, Flip: coptic-bound book

graphic design print creative coding

Well, Flip! uses p5.js to animate text as it falls and recomposes into new forms. Each frame was exported using Python and assembled in InDesign to create a printed flipbook. The project explores the tension between computational generation and physical print, combining creative coding with traditional bookbinding.
