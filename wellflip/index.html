Well, Flip: coptic-bound book

graphic design print creative coding

A p5.js-generated, coptic-bound flipbook, exploring the intersection of generative design and handmade bookbinding.

2025 · Graphic Designer

Animation · Graphic Design · Book Binding

CONCEPT

Generative code can produce infinite, perfect variations, but a handmade book is finite, physical, and imperfect. The piece explores this tension: the falling text creates a hypnotic loop that feels alive on screen, but freezing a single frame into a printed page captures a moment that cannot be exactly replicated. The flipbook format mirrors the loop, letting the viewer animate it with their own hands.

PROCESS

A p5.js sketch generates falling and recomposing letterforms, with parameters controlling speed, fragmentation, and recomposition patterns. Each frame was exported as an image sequence using Python, then laid out in InDesign for print. The pages were assembled and hand-bound using coptic stitch, chosen for its exposed spine that reveals the handmade quality of the object.

MATERIALS / FORMAT

Coptic-bound book, p5.js-generated interior pages, approximately 50 pages, A5 portrait.

REFLECTION

Bridging code-based generative work with a physical, hand-bound object taught me about the constraints each medium imposes. The unpredictability of the code output mirrors the unpredictability of hand-binding: both involve controlled processes with room for happy accidents. The project confirmed my interest in work that lives at the boundary of digital and physical craft.
